RIOFPS HYBRID 2.0 - TG + GL
===========================

Что это
-------
Готовая схема из двух частей:

1) RioBridge — обычный Fabric client mod для Minecraft 1.21.11.
   Именно он имеет доступ к игровому tick/render pipeline.

2) RioController — C++20 приложение с GUI RIO.
   Оно меняет настройки TG/GL через localhost 127.0.0.1:38765.

Никакого DLL injection, чтения/записи памяти другого процесса или process hiding нет.

ВАЖНО
------
Удали предыдущий RioFPS .jar из папки mods перед установкой этой версии,
потому что Fabric mod id у проекта такой же: riofps.

============================================================
1. СБОРКА FABRIC BRIDGE
============================================================

Открой терминал в папке:

    RioBridge

Если у тебя уже есть Gradle Wrapper:

    .\gradlew.bat build

Если используешь установленный Gradle:

    gradle build

После успешной сборки основной jar будет в:

    RioBridge\build\libs\RioFPS-2.0.0.jar

Скопируй его в:

    %appdata%\.minecraft\mods

Нужны:
- Minecraft 1.21.11
- Fabric Loader
- Fabric API для 1.21.11
- Java 21

============================================================
2. СБОРКА C++ RIO
============================================================

Установи Visual Studio 2022 с workload:

    Desktop development with C++

Запусти:

    x64 Native Tools Command Prompt for VS 2022

Перейди в:

    RioController

И выполни:

    build_controller.bat

Либо вручную:

    cl /std:c++20 /EHsc /W4 rio.cpp user32.lib gdi32.lib ws2_32.lib /link /SUBSYSTEM:WINDOWS /OUT:Rio.exe

После этого появится:

    Rio.exe

CMake-вариант:

    cmake -S . -B build
    cmake --build build --config Release

============================================================
3. ЗАПУСК
============================================================

1. Запусти Minecraft 1.21.11 через Fabric.
2. Убедись, что RioFPS присутствует в mods.
3. Зайди в мир / на сервер.
4. Запусти RioController\Rio.exe.
5. В верхней части GUI должно быть:

    BRIDGE: ONLINE

Если написано OFFLINE, controller сам повторяет подключение.

============================================================
4. УПРАВЛЕНИЕ
============================================================

Right Shift
    показать / скрыть окно RIO. Проверяется глобально, поэтому работает,
    когда Minecraft находится в фокусе.

ЛКМ по TG / GL
    включить / выключить.

ПКМ
    раскрыть настройки.

СКМ
    режим назначения бинда.

После СКМ нажми нужную клавишу.
Назначенные TG/GL бинды проверяются глобально и работают во время игры.

Esc во время назначения
    отмена.

Delete / Backspace
    очистить bind.

============================================================
5. TG
============================================================

TG реагирует только на PlayerEntity, который находится под реальным
crosshair Minecraft. Это не поиск игроков вокруг персонажа.

COMBA
    - ждет почти полный vanilla cooldown (0.99);
    - атакует через MinecraftClient#doAttack(), то есть через стандартный
      клиентский left-click attack path;
    - намеренно пропускает окно, в котором vanilla определяет атаку как crit.

KRIT
    - начинает рассматривать атаку при cooldown >= 0.90;
    - атакует только в реальном vanilla critical-hit состоянии;
    - при необходимости на момент проверки/удара снимает sprint state и
      сразу восстанавливает его;
    - итоговый урон остается серверным/vanilla.

============================================================
6. GL
============================================================

GL использует entity outline pipeline непосредственно внутри Minecraft.
Контур идет по отрендеренной модели сущности, а не рисуется C++ окном.

VISIBLE
    Только живые не-spectator игроки, которые не invisible и которых
    local player может видеть.

ALL
    Все PlayerEntity, известные client world, кроме local player.
    Vanilla outline pass позволяет видеть контур за геометрией.

WIDTH
    1..30.

COLOR
    RED / WHITE / BLUE.

============================================================
7. UNHOOK
============================================================

UnHook в C++:
- отправляет bridge команды TG OFF / GL OFF;
- отправляет UNHOOK;
- закрывает localhost socket;
- завершает Rio.exe штатно.

Fabric bridge остается загруженным до закрытия Minecraft — Fabric не
предназначен для безопасной runtime-выгрузки уже загруженного мода.
При потере соединения bridge автоматически выключает TG и GL.

============================================================
8. LOCALHOST PROTOCOL
============================================================

Controller подключается только к:

    127.0.0.1:38765

Команды:
TG_ENABLED 0|1
TG_MODE COMBA|KRIT
GL_ENABLED 0|1
GL_MODE VISIBLE|ALL
GL_WIDTH 1..30
GL_COLOR RED|WHITE|BLUE
PING
UNHOOK

Настройки не пишутся в отдельные config/friend файлы.
